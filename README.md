# Lawrence Phuka Chikapa - Portfolio

Personal portfolio for Lawrence Phuka Chikapa, a Malawian software developer and systems builder creating practical digital systems for education, administration, identity management, billing, communication, and community development.

## Live Website

- [Portfolio website](https://lawreay.github.io/portfolio/)
- Static deployment target: GitHub Pages (the same files can also be served by Vercel or any static host)

## Built With

- HTML5, CSS3, and JavaScript
- Bootstrap 5.3
- Bootstrap Icons
- Responsive, static-site architecture

## Featured Work

- HRMS for institutional human-resource administration
- NDC Identity System for student identity and ID-card management
- NDC Billing System for billing and invoice workflows
- Learn360 digital education platform
- DesMW developer-data platform
- Ntonda Online Quiz System

## Project Structure

## Run Locally

Open `index.html` in a browser, or serve the folder with any static web server. For example:

```text
php -S localhost:8000
```

Then visit `http://localhost:8000`.
